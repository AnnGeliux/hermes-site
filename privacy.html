Política de privacidad de Hermes

Vigente desde el 28 de octubre de 2026

1. Quién trata los datos

Hermes es una aplicación de escritorio de uso estrictamente personal, operada por Angel Palestina (aangel.palestina@gmail.com) en su propio equipo. No existe un servicio en la nube operado por el desarrollador, ni cuentas de usuario, ni acceso para terceros.

2. Qué datos de Google se solicitan

  • Gmail — lectura, búsqueda, clasificación y envío de mensajes de la cuenta del propio usuario.
  • Google Drive — lectura, descarga y carga de archivos del propio usuario.
  • Google Calendar — lectura y gestión de calendarios y eventos del propio usuario.
  • Datos básicos de perfil — dirección de correo y nombre, para identificar la cuenta autorizada.

3. Para qué se usan

Únicamente para ejecutar las tareas que el usuario le pide de forma explícita desde su equipo (por ejemplo, redactar o enviar un correo, subir un archivo o revisar la agenda). No se usan para publicidad, creación de perfiles, análisis de mercado, entrenamiento de modelos ni ninguna otra finalidad.

4. Dónde se almacenan

El contenido de los datos consultados y las credenciales OAuth se almacenan exclusivamente en el equipo del usuario, en el disco local. Las credenciales se guardan cifradas y nunca se envían al desarrollador ni a terceros.

5. Con quién se comparten

No se comparten con nadie. No hay venta, cesión, transferencia ni divulgación de datos de usuarios de Google a terceros, salvo obligación legal expresa. No se emplean herramientas de lectura de correo con fines publicitarios ni se emplean datos de Gmail para publicidad (cumplimiento de los requisitos de uso limitado de Google).

6. Uso limitado de los datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado. Los datos obtenidos de Google se usan solo para las funciones descritas y no se transfieren a terceros sin consentimiento explícito.

7. Cómo revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions o eliminando las credenciales locales del equipo. Al revocarlo, la aplicación deja de tener acceso de inmediato.

8. Conservación

Los tokens de acceso y de refresco se conservan en el equipo mientras el usuario mantenga la integración activa. El historial de conversación con el asistente se conserva localmente y el usuario puede borrarlo cuando quiera.

9. Cambios en esta política

Cualquier cambio se publicará en esta misma página. La fecha de la versión vigente figura al inicio del documento.
